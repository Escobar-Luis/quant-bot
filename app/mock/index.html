              How quant-bot learns

              One loop. The model only ever proposes; coded rules decide, and PRISM records the proof.

              1. 1
                Fetch

                Prices and headlines from allowlisted sites only. PRISM's guardrail checks each fetch first; blocked ones never reach the model.

                whereCoinbase · CryptoPanic · PRISM guardrails API
              2. 2
                Propose

                The model reads PRISM's open root-cause clusters and proposes one change to a rule, a parameter or its prompt, with a reason.

                whereNicrron API · nicrron/auto
              3. 3
                Backtest

                Code runs the new version on the same 4 fixed windows, then on the sealed window the model has never seen.

                whereour backtester, Python, deterministic
              4. 4
                Decide

                Four coded rules accept or reject the change. The model can't override them. Rejected versions never trade.

                whereour code · accept.py
              5. 5
                Observe and self-fix

                PRISM traces every run, scores it, clusters failures, patches the prompt, replays the failures and opens a draft PR only if 80%+ pass.

                wherePRISM by Block Convey

              Paper trading

              The live version trades fake money on BTC, ETH and SOL (crypto trades on Saturdays). The model suggests trades; code sizes them, sets stops, and can say no.

              Honesty rules

              • The sealed window starts after the model's training cutoff and uses renamed tickers.
              • Missing data stays "unknown". The bot skips the trade instead of guessing.
              • The agent stops and asks a human when its evidence runs out.
